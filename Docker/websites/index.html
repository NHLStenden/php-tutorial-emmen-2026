This screen indicates that the docker PHP development environment for NHL-Stenden is running! 🥳 You can now start coding, or... Check out the tiles for more useful information

You can add your files to the "student" folder. Any files not present in the public folder will not be displayed to the public. They can be used by your own files though!

Database

The database is accessible at localhost:3306. The default username is "root" with password "qwerty". Keep in mind, this is a root user with all permissions. To add another user, navigate to the .env file and uncomment the two DB_ lines and fill in the desired user. Afterwards, use docker-compose up to reinitiate the environment.

You use PHPMyAdmin at localhost:8080 to access the database or by using another tool like MySQL Workbench. The aforementioned login information still applies.
