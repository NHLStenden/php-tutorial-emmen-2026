# Afbeeldingen gegenereerd met ChatGPT

## Banner

Maak een websitebanner voor een gamewinkel met de naam "Ultimate Gamer". De banner moet 1080 pixels breed en 300 pixels hoog zijn.
De stijl moet in de stijl van gamers uit de jaren tachtig zijn: 8-bit pixels, donker, vierkante lettertypes enz.
