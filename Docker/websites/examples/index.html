Week Description HTML PHP
Week 1 Basic HTML Basic PHP During this seminar, students install Docker and an Integrated Development Environment (IDE) (see Appendix 7). The seminar introduces the principles of styling HTML pages using CSS. Students learn how classes and IDs can be used to style specific elements. The fundamentals of PHP syntax are introduced, after which students begin creating dynamic web pages by embedding PHP within HTML.
Week 2 Layouts Conditionals Students learn how modern web page layouts are created using CSS Grid and Flexbox. In PHP we look at how decisions are made using Boolean expressions.
Week 3 Positioning Arrays and loops In this week students learn how to position elements on a page. In PHP we look at storing lists of information and proces them using loops.
Week 4 Menus Functions In this week students learn how to setup a HTML menu. In PHP we will be looking at how to use and create functions to save development time and isolate functionality.
Week 5 Forms Processing forms In this week students learn how a user can input information in a web page and send it to a server for processing and validation.
Week 6 Printing webpages - In this week students learn how to make a webpage ready to be printed or exported to PDF using the browser&s print function in combination with @media queries.
