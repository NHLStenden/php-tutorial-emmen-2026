Week 4 - Menus - Functions

In this week students learn how to setup a HTML menu. In PHP we will be looking at how to use and create functions to save development time and isolate functionality.
Title Language Folder Description
A simple menu HTML 01 In this example we explore the most basic form of a navigation menu. In order to make it look like a menu we have to add a lot of css.
Menu with sub menus HTML 02 In this example we will be creating a main menu with sub menu items.
Menu with hidden sub menus HTML 03 In this example we will be creating a main menu with hidden sub menu items. Using CSS :hover we will be showing the menus when the main menu is being hovered. This is called a harmonica style.
Menu with hidden sub menus using `<summary>` HTML 04 In this example we move away from the <ul> to list menu items, but instead use the <details> which has built-in browser support for harmonica-like behavior. However, we cannot use a :hover event to open the sub menu. THe user must click on the <summary> element in order to open the sub menu.
Complex menus using CSS HTML 05 In this example we use modern CSS to display menus and submenus using flexbox and css anchors.
Functions : strings PHP 10 PHP has a lot of functions built-in you can use to help you program easier. Have a look at the references section for references to the PHP Reference pages.
Variable functions PHP 11 Information about PHP variables can be very useful when programming. Most often you want to check if a variable is of a certain type, for instance when recieving information from a file or HTML Form (see week 5).
User Defined Functions PHP 12 A user defined function is a function that you as a programmer create yourself. You give the function a name, add optional parameters and write the body of the function.
Function types PHP 13 Functions take parameters. To ensure that the function works properly, you can indicate a type of each parameter.
Type Juggling 1 PHP 14 In this example a few type coercion are demonstrated.
PHP Standard functions: Reading a file PHP 20 In PHP it is easy to read or write from a file. This can be usefull to process data files or include HTML.
Example with arrays and functions PHP 21 In this example we declare an array with 'records': every item in the main array is a collection of key-value pairs. With this array we will be building an HTML <table>.
Flex layout for cards revisited PHP 30 An earlier example is revisited using loops and arrays to display cards.
