# Week 4 - HTML - Menu with hidden sub menus using `<summary>`

In this example we move away from the `<ul>` to list menu items, but instead use the `<details>` which has built-in
browser support for harmonica-like behavior. However, we cannot use a `:hover` event to open the sub menu. THe user
must click on the `<summary>` element in order to open the sub menu.
