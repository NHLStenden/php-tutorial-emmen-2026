# Week 4 - HTML - Menu met verborgen submenu’s met behulp van `<summary>`

In dit voorbeeld stappen we af van de `<ul>` om menu-items weer te geven, maar gebruiken we in plaats daarvan de `<details>`, die ingebouwde
browserondersteuning biedt voor een harmonica-achtig gedrag. We kunnen echter geen `:hover`-gebeurtenis gebruiken om het submenu te openen. De gebruiker
moet op het `<summary>`-element klikken om het submenu te openen.
