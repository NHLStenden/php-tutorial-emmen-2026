# Week 2 - HTML - Flex-raster met automatische aanpassing van de afmetingen 

In dit voorbeeld zien we dat de HTML behoorlijk verschilt van het voorbeeld met de `display:grid`.

## Voordelen in dit specifieke voorbeeld

De zijbalk hoeft niet te worden geschaald. In dit geval gebruiken we een 'relatieve em-dash'-lengte die mooi meeschaalt.
De `<section>` hoeft dus ook niet te worden geschaald, omdat de zijbalk vast blijft staan. 

## Nadelen
* De eerste `<header>` maakt geen deel meer uit van de `<main>` of `<article>`.
* De aside maakt geen deel uit van de `<article>`, maar bevindt zich in plaats daarvan in `<main>`.
