#  Week 2 - HTML - Rasterdemo 2

Een demo met vier kaarten in een raster van 2 bij 2. 

In deze demo gebruiken we `grid-template-columns` om te bepalen hoe de kolommen zich moeten gedragen. In dit geval gebruiken we een vaste
kolom van `25vw` (25% van de weergavebreedte) en een tweede kolom waarvan de breedte door de browser wordt bepaald (`auto`).
