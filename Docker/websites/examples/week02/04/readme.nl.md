#  Week 2 - HTML - Raster met breuken

In deze demo maakt de `grid-template-columns` gebruik van breuken. 

Een ‘breuk’ wordt berekend door alle breuken bij elkaar op te tellen. Dit totale aantal delen wordt vervolgens gebruikt om de
horizontale ruimte te verdelen. In dit geval:

* 1fr
* 2fr

Dit leidt tot een totaal van 3 fracties. De horizontale ruimte wordt dus in 3 delen verdeeld. Eén deel wordt toegewezen aan de eerste kolom,
het tweede en derde deel worden toegewezen aan de tweede kolom. 

Dit zorgt er dus in feite voor dat 
* alle horizontale ruimte wordt benut
* de eerste kolom half zo groot is als de tweede kolom
