#  Week 2 - HTML - Grid demo 3

In this demo the `grid-template-columns` uses fractions. 

A 'fraction' is calculated by adding all the fractions. This total number of parts is then used to divide the space
of the horizontal space. In this case:

* 1fr
* 2fr

Leads to a total of 3 fractions. So the horizontal space is divided in 3 parts. One part is assigned to the first column,
the 2nd and 3rd are assigned to the second column. 

So, basically this will 
* make sure all of the horizontal space is taken up
* the first column is half the size of the second column
