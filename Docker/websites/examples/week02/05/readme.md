#  Week 2 - HTML - 12 column grid example

The 12 column grid is a popular way to setup a grid for web pages.

The number 12 is chosen because it can be divided by 1,2,3,4 and 6. So, calculating relative column sizes should be 
easier. For instance, 

* first column is 2fr
* second column must be twice the size, so 4 fr
* third column must be 1fr
* last column is 12 - 4 -1 = 7fr
