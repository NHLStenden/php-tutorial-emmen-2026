# Week 1 - PHP - "Hello World" met PHP

Het eenvoudigste PHP-programma: gewoon "Hello world" op het scherm weergeven. 

Net zoals we in het tweede voorbeeld hebben gezien, is er helemaal geen HTML, en toch geeft de browser het correct weer.

Een PHP-programma wordt geopend met de instructie `<?php`. Let op het volgende:

1. er is geen `>` om het element te sluiten!
2. er is geen `</php>`-instructie om het element te sluiten. 

Dit lijkt vreemd, aangezien we eerst hebben geleerd dat elk element aan deze regels moet voldoen. Het is niet verboden om een PHP-
programma af te sluiten met `?>`, maar als het aan het einde van het bestand staat, is het aanbevolen om dit weg te laten.
