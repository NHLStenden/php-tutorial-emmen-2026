# Week 1 - Example 3

View this example on [github](https://nhlstenden.github.io/php-tutorial-emmen-2026/Docker/websites/examples/week01/01).

The example in `index.html` is a more elaborate example, showcasing multiple elements contained in one another:

* main 
  * article
    * header
    * section
        * header
        * paragraphs of text
  * aside
  * footer

Notice that the structure and the flow on-screen are not quite the same. You might expect that some parts might be
indented and that the `<aside>` actually is on the side of the screen. Unfortunately this is not the case. The structure
of the HTML has very little to do with your expectations of the visualisation on-screen. 

Of course this can be improved. This can be achieved by using instruction for styling. Later in this module we will 
take a look on how to visual style an article/page like this. If you would like to take a peek, have a look at the 
[second file](./index2.html). Take a look at the styling contained in de the `<head><style>....</style></head>` part 
of the HTML file.
