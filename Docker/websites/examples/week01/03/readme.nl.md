# Week 1 - HTML - Semantische HTML

Dit voorbeeld toont een aantal semantische HTML-elementen.

Het voorbeeld in `index.html` is een uitgebreider voorbeeld, waarin meerdere elementen binnen elkaar zijn genest:

* main 
  * article
    * header
    * section
 * header
 * alinea’s tekst
  * aside
  * footer

Merk op dat de structuur en de weergave op het scherm niet helemaal hetzelfde zijn. Je zou misschien verwachten dat sommige delen
ingesprongen zijn en dat `<aside>` daadwerkelijk aan de zijkant van het scherm staat. Helaas is dit niet het geval. De structuur
van de HTML heeft maar weinig te maken met je verwachtingen over de weergave op het scherm. 

Bekijk in het volgende voorbeeld hoe dit kan worden gerealiseerd met behulp van **CSS**.
