# Week: 1

## Introduction (Kick-off)

* Teaching method : Lecture
* Duration : 1 lesson

### Learning objectives

By the end of this session, students will:

* understand the structure and content of the Web Development module;
* be familiar with the teaching methods;
* understand the assessment procedures;
* know what is expected throughout the module

### Content

During the introductory lecture, students receive an overview of:

* the organisation of the module;
* teaching methods;
* assessment procedures;
* required literature and software;
* weekly planning;
* learning outcomes.

## Web Development Seminar

* Teaching method: Seminar
* Duration: 3 × 2 teaching hours

### Learning objectives

By the end of this seminar, students will be able to:

* install Docker;
* install and configure an IDE of their choice;
* create a logical folder structure;
* organize source files using proper indentation;
* add images to a web page;
* apply external CSS stylesheets;
* use HTML classes and IDs correctly;
* understand the fundamentals of PHP syntax;
* create HTML pages containing PHP code.

### Content

During this seminar, students install Docker and an Integrated Development Environment (IDE) (see Appendix 7). The
seminar introduces the principles of styling HTML pages using CSS. Students learn how classes and IDs can be used to
style specific elements. The fundamentals of PHP syntax are introduced, after which students begin creating dynamic web
pages by embedding PHP within HTML.

### Preparation / Individual assignments

Students should:

* install Docker;
* install their preferred IDE;
* consult the introductory lecture where necessary;
* complete the Week 1 assignments.

# Week 2

* Teaching method: Seminar
* Duration: 3 × 2 teaching hours

## Web Development Seminar

### Learning objectives

By the end of this seminar, students will be able to:

* use CSS Grid and Flexbox layouts;
* explain the CSS box model;
* use HTML entities correctly;
* apply conditional statements in PHP;
* distinguish between if/else and switch statements;
* use comparison and logical operators appropriately.

### Content

Students learn how modern web page layouts are created using CSS Grid and Flexbox.

The seminar explains the CSS box model, including:

* content;
* padding;
* borders;
* margins.

Students are then introduced to conditional statements, enabling programs to execute different actions depending on
specific conditions. These concepts form an essential foundation for dynamic web applications.

### Preparation

Complete all Week 2 assignments.

# Week 3

* Teaching method: Seminar
* Duration: 3 × 2 teaching hours

## Web Development Seminar

### Learning objectives

By the end of this seminar, students will be able to:

* working with CSS pseudo selectors;
* position text on images;
* use repetition structures (loops);
* distinguish between while, do-while, for, and foreach loops;
* use arrays as collections;
* combine arrays with loops effectively.

### Content

* Students continue developing their HTML and CSS skills by working with links, images and interactive styling.
* The seminar introduces repetition structures (loops), enabling repetitive tasks to be automated efficiently.
* Students also learn how arrays can be used to store collections of data and how arrays and loops work together to
  solve programming problems efficiently.

### Preparation

Complete all Week 3 assignments.

# Week 4

* Teaching method: Seminar
* Duration: 3 × 2 teaching hours

## Web Development Seminar

### Learning objectives

By the end of this seminar, students will be able to:

* create structured navigation menus in HTML;
* understand the purpose and advantages of functions in PHP;
* use built-in PHP functions;
* create their own functions;
* explain the concepts of scope, pass by value, and pass by reference;
* apply functions to improve the readability and maintainability of their code.

### Content

This seminar focuses on creating navigation menus in HTML and introducing functions in PHP.

Students learn how functions reduce code duplication by encapsulating reusable functionality. They will work with both
built-in PHP functions and user-defined functions while exploring function parameters, return values and variable scope.

### Preparation / Individual assignments

Complete all Week 4 assignments.
