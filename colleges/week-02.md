
# Week 2

* Teaching method: Seminar
* Duration: 3 × 2 teaching hours

## Web Development Seminar

### Learning objectives

By the end of this seminar, students will be able to:

* use CSS Grid and Flexbox layouts;
* explain the CSS box model;
* use HTML entities correctly;
* apply conditional statements in PHP;
* distinguish between if/else and switch statements;
* use comparison and logical operators appropriately.

### Content

Students learn how modern web page layouts are created using CSS Grid and Flexbox.

The seminar explains the CSS box model, including:

* content;
* padding;
* borders;
* margins.

Students are then introduced to conditional statements, enabling programs to execute different actions depending on
specific conditions. These concepts form an essential foundation for dynamic web applications.

Complete all Week 2 assignments.
