
# Week 4 - Menus and PHP Functions

* Teaching method: Seminar
* Duration: 3 × 2 teaching hours

## Web Development Seminar

### Learning objectives

By the end of this seminar, students will be able to:

HTML
* create structured navigation menus in HTML;

PHP
* understand the purpose and advantages of functions in PHP;
* use built-in PHP functions;
* create their own functions;
* explain the concepts of scope, pass by value, and pass by reference;
* apply functions to improve the readability and maintainability of their code.

### Content

This seminar focuses on creating navigation menus in HTML and introducing functions in PHP.

Students learn how functions reduce code duplication by encapsulating reusable functionality. They will work with both
built-in PHP functions and user-defined functions while exploring function parameters, return values and variable scope.

### Preparation / Individual assignments

Complete all Week 4 assignments.
