
# Week 3 - Positioning and PHP loops

* Teaching method: Seminar
* Duration: 3 × 2 teaching hours

## Web Development Seminar

### Learning objectives

By the end of this seminar, students will be able to:

* apply hover effects;
* position text on images;
* use repetition structures (loops);
* distinguish between while, do-while, for, and foreach loops;
* use arrays as collections;
* combine arrays with loops effectively.

### Content

* Students continue developing their HTML and CSS skills by working with links, images and interactive styling.
* The seminar introduces repetition structures (loops), enabling repetitive tasks to be automated efficiently.
* Students also learn how arrays can be used to store collections of data and how arrays and loops work together to
  solve programming problems efficiently.

### Preparation

Complete all Week 3 assignments.
