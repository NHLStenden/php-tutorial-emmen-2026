
# Week 5

* Teaching method: Seminar
* Duration: 3 × 2 teaching hours

## Web Development Seminar

### Learning objectives

By the end of this seminar, students will be able to:

* create HTML forms;
* process form data using PHP;
* retrieve and display user input;
* perform basic input validation;
* combine HTML forms with PHP to create interactive web pages.

### Content

Students learn how HTML forms are used to collect user input and how PHP can process submitted data.

Topics include:

* GET and POST requests;
* retrieving form data;
* displaying submitted information;
* validating user input;
* creating interactive web pages.

### Preparation / Individual assignments

Complete all Week 5 assignments.
